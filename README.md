# 🛡️ StreamShield – Backend

**StreamShield** is an AI-powered platform that enables streamers and content creators to **protect their privacy in real-time** during live streams. This backend handles stream ingestion, real-time AI-based detection and blurring of sensitive content (like personal documents, notifications, credit cards, Login forms , URL's ), and communication with the frontend. 

This repository contains the **Backend** codebase, responsible for stream processing, ML model integration, authentication, and data management.

## 🔧 Core Responsibilities

- 🧠 AI/ML model for detecting sensitive regions in video streams
- 🔲 Real-time blurring using OpenCV , Beeping Sensitive words from Audio
- 🔄 Video frame processing pipeline (FFmpeg)
- 👮 User authentication and role-based access
- 🗃️ Logs and history management for streaming sessions
